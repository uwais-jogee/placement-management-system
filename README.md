# Placement Management System

The Placement Management System is a full-stack web application for universities and students to manage and oversee the industrial placement process. Key placement related tasks including placement authorisation requests, communication, tutor visit scheduling, and placement data management are centralised and automated to improve efficiency and reduce the administrative burden.

[View Hosted Environment](https://placement-management-system-tl81.onrender.com)

## 👥 User Roles & Features

The application has four user roles with different permissions and functionalities:

- **Student**: Submit placement requests, view scheduled visits, message tutors, complete evaluations, access resources, generate AI cover letters.
- **Tutor**: View assigned students, schedule visits with calendar and travel suggestions, message students.
- **Admin**: Manage placement approvals, reassign tutors, view all placement and company records.
- **User Manager**: View, create, edit and delete user accounts.


## 🛠️Technology Stack

- **Backend:** Java Spring Boot  
- **Database:** MySQL  
- **Frontend:** Thymeleaf, Tailwind CSS, JavaScript  
- **External APIs:** Microsoft Graph API, Google Maps Platform, MailerSend API
